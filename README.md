# Personal Portfolio

Personal portfolio website built with React, Vite, and Tailwind CSS.

## Features
- Responsive design
- Project showcase
- Experience section
- Skills section
- Contact form powered by EmailJS

## Live Demo
https://saadfoda-portfolio.vercel.app/

## Technologies
- React
- Vite
- Tailwind CSS
- EmailJS

## Installation

npm install
npm run dev
